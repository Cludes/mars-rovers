# Mars Rover Mission Control

An interactive dashboard for NASA's Mars rovers. Browse each rover's mission profile, stats, and fun facts, and pull real imagery from NASA's public APIs.

**Live demo:** https://cludes.github.io/mars-rovers/

## Features

- Profiles for NASA's Mars rovers (Perseverance, Curiosity, and more) with landing site, launch date, stats, and mission facts
- Real photos from NASA's image library
- Mission elapsed time tracked in Martian sols
- Fully static - runs in the browser, no backend

## Structure

- `index.html`, `rovers.js`, `style.css` - the app
- `data/` - rover and mission data

## Running locally

```bash
npx serve .
```
